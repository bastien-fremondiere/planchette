# Roadmap

## Near-term

1. Add support for placing up to four different images on the same A4 page.
2. Add portrait or landscape page selection.
3. Add a copy count mode for multi-page export.
4. Add direct drag-and-drop input.

## Broader toolbox ideas

1. Rearrange PDF pages.
2. Convert image batches to PDF.
3. Prepare label sheets.
4. Merge and compress PDFs.
5. Simple unit and paper-size converters.

## Design follow-up

1. Finalize the logo and favicon.
2. Add an about page once the tool set expands.
3. Introduce a small visual identity kit for social sharing and repository polish.
